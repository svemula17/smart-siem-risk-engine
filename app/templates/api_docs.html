REST API Reference

Integrate the Smart SIEM Risk Engine with your existing SOC tools. The endpoints below allow you to programmatically hunt threats, manage blocklists, and extract normalized intelligence data.

Health Checks

Monitor the uptime and operational status of the Risk Engine.

GET /health

Perform a basic heartbeat health check on the API layer.

Alert Endpoints

Retrieve structured and normalized network alerts processed by the platform.

GET /raw-alerts

Fetch the original, unparsed JSON network logs.

GET /scored-alerts

Fetch alerts after they have passed through the Heuristic and Machine Learning scoring pipeline.

GET /blocked-ips

Export a JSON array of dynamically blocked IP addresses to feed into your organization's firewall automation layer.

Metrics & Stats

Extract statistical intelligence regarding engine performance and detection rates.

GET /evaluation-results

Get detailed truth-label evaluations for the threat detection algorithms.

GET /metrics

Fetch quantitative platform metrics (Total Processed, Blocked Entities, Overall Precision).

Reports Base

Automated intelligence reports.

GET /reports

Retrieve paths and metadata for all generated incident and summary reports.

Dashboard Actions

The core interactive routes utilized by the SIEM UI for active threat hunting and response.

GET /dashboard

Serves the main SIEM user interface HTML.

POST /api/hunt

Execute a complex Threat Hunt string query (e.g. mitre:T1110 risk:>80 action:block). Returns matching historical telemetry securely encoded.

POST /api/block_ip

Manually force add a target IP Address to the global drop list.

POST /api/unblock_ip

Manually remove a target IP Address from the global drop list.

POST /api/internal/broadcast

Internal pipeline webhook used by run.py to stream massive volumes of alerts to the WebSocket hub.

Reset Data

Administrative environment controls.

POST /reset

Reset the local intelligence cache and database simulating a fresh SOC deployment.
